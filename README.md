# Проект банковский счет.

## Проект банковский счет - это веб-приложение на Python для скрытия банковских карт и счетов.


## Установка:
 1. Клонируйте репозиторий через ssh:

git clone git@github.com:sergey0875/test_project.git

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Тестирование
Проект покрыт модульными тестами с использованием библиотеки `pytest`
протестированы модули в папке src:


widget.py   
masks.py  
progressing.py  

## Добавлен модуль generators с функциями и генераторами

1. filter_by_currency
, которая принимает на вход список словарей, представляющих транзакции.
2. генератор 
transaction_descriptions
, который принимает список словарей с транзакциями и возвращает описание каждой операции по очереди.
3. генератор 
card_number_generator
, который выдает номера банковских карт в формате 
XXXX XXXX XXXX XXXX

### Запуск тестов
команда: pytest

### Покрытие тестами 100%
Провера покрытия: pytest --cov
