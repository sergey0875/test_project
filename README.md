## Добавлен модуль generators с функциями и генераторами

1. filter_by_currency
, которая принимает на вход список словарей, представляющих транзакции.
2. генератор 
transaction_descriptions
, который принимает список словарей с транзакциями и возвращает описание каждой операции по очереди.
3. генератор 
card_number_generator
, который выдает номера банковских карт в формате 
XXXX XXXX XXXX XXXX

## Добавлен модуль decorators.

1. Отслеживает результат: Если функция выполняется успешно, записывает сообщение «имя_функции ok».
2. Обрабатывает ошибки: Если происходит сбой, ловит исключение, записывает тип ошибки («имя_функции error: тип_ошибки») и пробрасывает её дальше.
3. Выбирает способ вывода:
   - Если передан filename, лог дописывается в файл.
   - Если файл не указан, лог выводится в консоль.
4. Сохраняет метаданные: Благодаря @wraps(func) оригинальное имя и документация функции my_function не теряются

## Добавлен модуль utils и external_api

1. Функция которая принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях. 
2. функция, которая принимает на вход транзакцию и возвращает сумму транзакции (
amount
) в рублях. Если транзакция была в 
USD
 или 
EUR
, происходит обращение к внешнему API для получения текущего курса валют и конвертации суммы операции в рубли.
